# Baselines

Baseline files generated by `--write-baseline` go here. They are not
committed by default (see the repo's `.gitignore`) since a baseline is
specific to the codebase it was generated against and goes stale quickly.

Generate one with:

```bash
python -m scanner.main path/to/plugin --write-baseline baselines/my-plugin.json
```

See [`README.md`](../README.md#quick-start) for the full CLI reference.
